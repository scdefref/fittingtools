一、快速上手

  1. 录入数据 —— 左侧表格逐行输入 X-Y，或点击"粘贴数据"从 Excel 复制，或"导入文件"加载 .xlsx / .csv。
  2. 拟合全部 —— 点击顶部"拟合全部"，工具会用 6 个并行 Web Worker（任务队列模式）对全部 1430 个候选方程做拟合，通常 1~3 秒完成。
  3. 看结果 —— 右侧"拟合结果"面板默认按当前排序方式（推荐 AIC）排列。点击任意方程卡片可切换图表主曲线，点击"★ 收藏"可在图表上叠加显示。
  4. 导出 —— "导出 Excel(最佳)"导出当前选中方程的参数 + 预测工具；"导出排名表"导出当前筛选/排序后的全部结果排名表（含 CV-R² 防过拟合指标）；"导出图表"导出 PNG / 位图封装 SVG。
提示：工具会自动从数据特征推断每类方程的初值，并行多起点搜索避免局部最优。

1.1 数据录入

  • 手动输入：点击"＋ 添加行"或"＋ 添加10行"逐行输入；表内双击单元格直接编辑；点击行首 ⚪ 图标可禁用该行（不参与拟合）。
  • 粘贴：点击"📋 粘贴数据" → 从 Excel / WPS 复制后粘贴到文本框，工具自动识别分隔符（制表符 / 逗号 / 空格）并识别表头。
  • 导入文件：点击"📁 导入文件" → 选择 .xlsx / .xls / .csv → 在弹窗中指定 X 列、Y 列所在工作表。
  • 生成经验频率：做洪水 / 暴雨频率分析时，先在 Y 列填入原始年极值系列（无需排序），点击"📊 生成经验频率"自动按 P = m/(n+1)（m 为降序排名，1=最大值）排频并写入 X 列（按 P 升序）。
拟合后"残差"列会显示该数据点的学生化残差（|t|>2 浅橙色，|t|>3 红色高亮为强离群点）。

1.2 拟合与结果

点击"拟合全部"后，右侧结果面板会列出所有成功拟合的方程（R²>0）。您可以使用分类筛选、关键词搜索、收藏等功能快速定位感兴趣的模型。

结果列表支持三种视图：

  • 卡片（默认）：显示方程名称、R²、统计量，可展开参数详情。
  • 排名表：类似 TableCurve 的密集表格，点击列头可排序。
  • 对比：将多个方程加入对比池（最多8个），并排显示参数与统计量。

三、拟合与结果解读

拟合方式：自动遍历全部 1430 方程，默认按 AIC 排序展示（推荐，避免 R² 过拟合）；可在右侧"分类"下拉中只看某一类，或用"搜索"框按名称关键字过滤。支持按 CV-R²（留一交叉验证）排序以识别过拟合模型。

3.1 关键统计量

点击卡片"参数详情 ▼"查看全部：

  • R²（决定系数）：越接近 1 越好。≥ 0.95 通常认为拟合优良；0.7~0.95 视场景可接受；< 0.7 需排查数据或换模型。
  • 调整 R²：在 R² 基础上惩罚参数个数（避免"用 10 个参数强行拟合 5 个点"），用于比较多参数数模型——同等 R² 下取调整 R² 更高的。
  • SEE（标准误）：残差的标准差，越小越好，与 y 同量纲。
  • F 统计量 / p 值：整体显著性检验。p < 0.05 表示模型整体显著（至少有一个系数非零）。
  • AIC / BIC（信息准则）：综合权衡拟合优度与参数复杂度，越小越好。比单纯 R² 更能防过拟合，是默认推荐排序指标。AIC 差距 >5 视为显著差异。
  • CV-R²（留一交叉验证 R²）：用 PRESS 统计量做近似留一交叉验证。CV-R² 远低于训练 R² 说明模型过拟合（参数多但泛化差），应优先选 CV-R² 接近训练 R² 的简洁模型。
  • 参数个数：越少越简洁，但拟合可能较差——同等 R² 下选参数少的（奥卡姆剃刀）。
注意：数学上 R² 最高 ≠ 物理上最合理。务必检查参数值是否符合物理意义（例如速率常数应为正、衰减指数应为负等）。
3.2 退化拟合

当 n - p < max(3, 0.25n)（n 为数据点数，p 为参数个数）时，工具会标记该方程为 ⚠ 退化拟合。这表示模型参数过多，曲线强行穿过每一个点，但预测能力极差，工程上不可用。出现此警告时，应优先选择参数更少的方程，或补充更多数据。

四、图表视图

顶部三个标签切换：

  • 散点 + 拟合曲线：默认视图，显示原始数据 + 当前选中方程的拟合曲线。
  • 残差图：y_pred - y 散点，用于判断系统偏差（漏掉的高阶项、异方差性等）。
  • 经验频率对比：频率分析时显示数据点 vs 理论频率曲线。

勾选 "显示置信区间/预测区间" 后叠加 95% 置信带（曲线本身的不确定度）和预测带（单点预测的离散度）。勾选 "叠加已选(星标)曲线" 可同时显示多条曲线对比。勾选 "稳健拟合(Huber)" 启用 IRLS 鲁棒拟合，对离群点不敏感（对所有方程有效）。

五、导出功能

  • 导出 Excel(最佳)：将当前选中方程的"拟合摘要 + 预测工具 + 数据与预测"合并为一个工作表，改参数后预测 Y 自动重算。
  • 导出图表：PNG 或 SVG（位图封装），可指定宽度 / 高度。
  • 单方程导出：结果卡片的"📄 导出此方程"——支持任意候选方程（不仅限于当前显示的最佳方程），便于报告附录罗列多种模型对比。
提示：Excel 预测工作表中修改"参数值"单元格时，"预测 Y"公式会自动重算——可作为简单的"What-if"工具。

六、频率分布（皮尔逊 III / 耿贝尔 / 对数正态）

重要前提：X 列必须是经验频率 P (%)（取值 0 < P < 100），Y 列为设计值（如洪峰流量、年最大日雨量）。
频率分布类方程使用说明：若拟合皮尔逊III型/耿贝尔/对数正态频率曲线，X列应为经验频率P(%)，Y列为设计值（如洪峰流量）。可先在Y列粘贴原始系列数据，再点击"生成经验频率"按钮，将自动按数学期望公式 P=m/(n+1) 排频并填入X列（按P升序）。

推荐工作流：

  1. Y 列填入原始年极值系列（无需排序）。
  2. 点击"📊 生成经验频率" → 工具按 P = m/(n+1)（m 为降序排名，1=最大值）自动排频并写入 X 列（按 P 升序）。
  3. 点击"拟合全部" → 在右侧"分类"中选"水利专业-频率分布"查看三种分布结果。
  4. 比较 R² 与适线图（经验频率对比视图），选择最符合水文规律的分布。

调参提示：皮尔逊 III 适线对 Cs 偏度系数敏感；若数据偏度大但 R² 不理想，可在水文频率分析中按经验值 Cs/Cv ≈ 2~5 约束。

七、水利专业公式

  • 暴雨强度 i = A/(t+b)ⁿ：x=降雨历时 t (min)，y=降雨强度 i (mm/min)，工具提供多组初值提升拟合鲁棒性。
  • 霍顿下渗 f = f_c + (f₀-f_c)·exp(-β·t)：f₀ 初始下渗率、f_c 稳渗率、β 衰减系数。
  • 马斯京根槽蓄 S = K·W：S 为槽蓄量，K 为槽蓄系数（h），W = x·I + (1-x)·O 需用户在表外按试算的 x 值预先算好作为 X 列。

八、自定义方程

支持用户输入任意 y = f(x, 参数) 表达式，工具自动将其加入拟合池与结果列表。

  1. 在左侧"自定义方程"区域点击"＋ 添加自定义方程"。
  2. 输入：方程名称、参数列表（a, b, c, ...）、数学表达式（JS 语法，可用 exp, log, sin, cos, tan, power, sqrt, atan, tanh, sinh, cosh 等函数）。
  3. 提供初始猜测可大幅提升非线性方程拟合成功率。
  4. 参数边界约束：填 min1,max1;min2,max2;...，可大幅提升含物理约束的方程拟合成功率。例如速率常数 a≥0：写 0,;...。

示例：参数 a,b,c，表达式 a + b*exp(c*x)（指数函数）。要 a≥0、b 在 0~100：边界填 0,;0,100;。

九、常见问题与贴士

拟合历史：左侧"拟合历史"下拉保存最近 10 次拟合的数据快照与最佳方程。点选某条记录可一键恢复数据（不会自动拟合，需再点"拟合全部"）。
  1. 拟合失败 / R² 全是 NaN：检查数据是否含 NaN / 空行；某些方程需要 x > 0 或 y > 0，可勾选有问题的行禁用。
  2. R² 很高但残差有系统偏差：查看"残差图"，若呈 U 形说明漏掉了二次项；若呈扇形说明有异方差，可尝试 y 取 ln。
  3. 多组结果 R² 几乎相同：优先选参数少的（调整 R² 更高的）；同时检查参数值是否合理。
  4. 想看某一类方程：右侧"分类"下拉筛选；或用"搜索"框按名称关键字（如"指数""对数""峰值"）。
  5. 数据点很多（> 500）拟合慢：工具默认 6 线程并行仍可在数秒内完成；若想更快，可在左侧禁用部分点。
  6. 想对比多条曲线：在结果列表对多条曲线分别点"★ 收藏"，然后勾选"叠加已选(星标)曲线"。
  7. 导出 Excel 后预测 Y 不重算：检查 Excel 是否启用了"自动重算"（公式 → 计算选项 → 自动）。
  8. 要全屏查看曲线：将左右面板收起（点击面板标题右侧 ‹ 或 › 图标），仅留中间图表。
  9. 离群点筛选：右侧可勾选"隐藏含离群点"自动过滤掉任何数据点残差 |t|>2 的方程。
